**ID:** TC-024
**Название тест-кейса:** Кнопка скачивает тестовый файл
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Кнопка „Скачать тестовый файл“ скачивает файл под именем cucumber-example.jpg, размер больше 0 (P1)» + «Тост „Файл cucumber.jpg скачан!“ появляется после скачивания (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено; каталог загрузок очищен перед прогоном
**Шаги:**
1. Кликнуть кнопку «Скачать тестовый файл»
2. Сразу после клика проверить появление тоста (тост живёт секунды)
3. Дождаться завершения скачивания
4. В каталоге загрузок убедиться, что есть файл cucumber-example.jpg размером больше 0
**Ожидаемый результат:**
В каталоге загрузок есть файл с именем cucumber-example.jpg, размер больше 0.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Каталог загрузок очищать перед прогоном — иначе появится «cucumber-example (1).jpg». В автотесте каталог загрузок задаётся в параметрах Chrome (опция download.default_directory). Тост после скачивания: по клиентскому коду заложен («Файл cucumber.jpg скачан!»), в headless-прогоне не зафиксирован (замер 2026-10-09) — в автотесте не проверяется, проверяется вручную в headed-режиме (Текущее поведение стенда, ручной ориентир). Имя в тосте — исходное (cucumber.jpg), сохраняется файл под именем cucumber-example.jpg.

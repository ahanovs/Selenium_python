**ID:** TC-015
**Название тест-кейса:** Поле «Комментарий»: границы maxlength 499/500/501
**Связанные требования:** Блок 1, пункт чек-листа дословно: «Поле „Комментарий“ ограничено 500 символами при наборе с клавиатуры — maxlength работает (P2)». Границы 499/500/501 — нижняя, точка, верхняя по технике граничных значений
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Ввести в поле «Комментарий» строки из таблицы (набор с клавиатуры, посимвольно)
2. Проверить длину значения: выбрать поле в панели Elements и выполнить в консоли DevTools $0.value.length
**Ожидаемый результат (таблица решений):**

| Введено символов | Длина значения в поле | Сообщение об ошибке |
|---|---|---|
| 499 | 499 — принято целиком | нет |
| 500 | 500 — принято целиком | нет |
| 501 | 500 — обрезано до границы | нет |

**Приоритет:** Medium
**Статус:** Автоматизирован
**Примечания:** Кейс автоматизируемый: посимвольный ввод сотен символов вручную не выполняется, ручной прогон заменяется автотестом (send_keys). Вставка из буфера не измерялась — см. ручной ориентир в чек-листе. Замер 2026-10-07: maxlength обрезает при наборе; программная установка значения обходит maxlength.

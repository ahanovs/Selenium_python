**ID:** TC-050
**Название тест-кейса:** DELETE /users/me/ без корректного current_password аккаунт не удаляет
**Связанные требования:** Блок 4, пункты чек-листа: «DELETE /me с неверным current_password → 403, пользователь НЕ удалён» + «DELETE /me без тела → 400 required»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован; access в наличии.
**Шаги:**
1. DELETE /api/v1/users/me/ с телом {"current_password": неверный пароль}
2. Проверить код и тело; GET /me — убедиться, что аккаунт жив
3. DELETE /api/v1/users/me/ без тела
4. Проверить код и тело
**Ожидаемый результат:**
1) 400 {"current_password":["Invalid password."]}; GET /me → 200 (аккаунт не удалён). 2) 400, ошибка «current_password: required».
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Замеры 2026-10-22, уточнено автотестом: неверный current_password с ЖИВЫМ токеном даёт 400 «Invalid password.»; 403 «Токен недействителен» — ответ на отозванный токен (см. TC-055), в первом замере эти ветки смешались. После теста аккаунт жив — стандартная уборка с ВЕРНЫМ паролем.

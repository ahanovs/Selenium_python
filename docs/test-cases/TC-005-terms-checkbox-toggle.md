**ID:** TC-005
**Название тест-кейса:** Чекбокс устанавливается и снимается кликом
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Чекбокс „Согласен с условиями“ переключается кликом, состояние отображается (P1)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть по чекбоксу «Согласен с условиями использования»
2. Кликнуть по чекбоксу ещё раз
**Ожидаемый результат:**
После шага 1 чекбокс отмечен; после шага 2 чекбокс снят.

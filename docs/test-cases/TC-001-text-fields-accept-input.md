**ID:** TC-001
**Название тест-кейса:** Текстовые поля принимают ввод и отображают введённое значение
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Каждое текстовое поле (имя, email, комментарий) принимает ввод и отображает введённое значение (P1)» + «Поля принимают ввод с клавиатуры по символам (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть в поле «Имя», ввести с клавиатуры по символам «Тест Юзер»
2. Сразу после ввода проверить отображение в поле
3. Повторить для поля «Email» — test@example.com и поля «Комментарий» — «Проверка ввода»
4. Нажать Tab (увести фокус из поля)
5. Проверить отображение всех трёх полей
**Ожидаемый результат:**
Во время набора очередной символ появляется в поле после каждого нажатия клавиши. Поле «Имя» — «Тест Юзер»; поле «Email» — test@example.com; поле «Комментарий» — «Проверка ввода». Значения не искажены и не очищены ни сразу после ввода, ни после ухода фокуса.
**Приоритет:** High
**Статус:** Автоматизирован
**Примечания:** Объединено: посимвольный набор и итоговое значение — одна операция ввода, проверяется и процесс, и результат; ожидаемые значения перечислены по каждому полю отдельно, чтобы падение указывало на конкретное поле. Уход фокуса — Tab (клик по пустой области ненадёжен из-за геометрии страницы).

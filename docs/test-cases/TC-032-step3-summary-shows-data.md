**ID:** TC-032
**Название тест-кейса:** Сводка на шаге 3 показывает данные шагов 1–2
**Связанные требования:** Блок 3, пункты чек-листа дословно: «Сводка показывает данные шагов 1–2: имя, email, телефон, состояние уведомлений, тему и язык (P1)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Заполнить шаг 1: имя «Иван Тестов», email «ivan@test.ru», телефон «+7 999 123-45-67»; кликнуть «Далее»
2. На шаге 2 включить уведомления, оставить язык «Русский» по умолчанию и выбрать «Светлая»; кликнуть «Далее»
**Ожидаемый результат:**
Сводка показывает введённые данные: имя — Иван Тестов; email — ivan@test.ru; телефон — +7 999 123-45-67; состояние уведомлений — «Включены»; тема — light; язык — ru (значение по умолчанию). Значения темы и языка соответствуют выбранному (текущее поведение стенда — внутренние коды; точное представление названиями — ручной ориентир).
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Тема и язык отображаются внутренними кодами — текущее поведение стенда (ручной ориентир). Эмодзи и флаги в текстах зависят от системы — сравнивать по подстроке без эмодзи. Покрытие всех вариантов темы, языка и уведомлений — отдельный кейс TC-036 (P2).

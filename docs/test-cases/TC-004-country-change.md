**ID:** TC-004
**Название тест-кейса:** Выбранную страну можно сменить
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Выбранную страну можно сменить на другую, кнопка списка обновляется (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Открыть список стран и выбрать «Россия»
2. Открыть список стран снова
3. Выбрать «Германия»
**Ожидаемый результат:**
Кнопка отображает «Германия», а не «Россия».

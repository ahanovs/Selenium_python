**ID:** TC-063
**Название тест-кейса:** Интеграция UI→API: регистрация через форму видна API
**Связанные требования:** Блок 5, пункт чек-листа: «Регистрация через UI-форму, затем логин через API теми же кредами → 200, /me возвращает тот же email» (P1)
**Предусловия:** Фронт и API доступны; уникальный email на прогон.
**Шаги:**
1. Зарегистрироваться через UI-форму `/sign_up` (валидные данные)
2. Дождаться входа в приложение
3. `POST /api/v1/jwt/create/` с теми же кредами, что введены в форме
4. `GET /api/v1/users/me/` с полученным access
5. `DELETE /api/v1/users/me/` с current_password (уборка)
**Ожидаемый результат:**
Шаг 2 — пользователь в приложении. Шаг 3 — 200. Шаг 4 — 200, `email` в ответе совпадает с введённым в форме (UI и API работают с одной базой). Шаг 5 — 204.

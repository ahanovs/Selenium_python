**ID:** TC-061
**Название тест-кейса:** Кнопка регистрации закрыта клиент-гейтом по силе пароля
**Связанные требования:** Блок 5, пункт чек-листа: «Кнопка „Зарегистрироваться“ неактивна, пока пароль не пройдёт клиентскую проверку силы» (P2)
**Предусловия:** Фронт доступен, открыта `/sign_up`.
**Шаги:**
1. Заполнить Email валидным значением, Пароль — `abc`
2. Проверить состояние кнопки «Зарегистрироваться»
3. Заменить пароль на сильный (не короче 8, не числовой, не словарный)
4. Проверить состояние кнопки
**Ожидаемый результат:**
Шаг 2 — кнопка disabled (клик невозможен). Шаг 4 — кнопка enabled.
**Приоритет:** Medium
**Статус:** Not Executed
**Примечания:** Замер 2026-10-23. Граничную длину/порог силы клиент не раскрывает — кейс фиксирует класс «слабый/сильный», не границу.

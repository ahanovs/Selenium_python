**ID:** TC-015
**Название тест-кейса:** Текущее поведение стенда: поле «Комментарий» принимает более 500 символов
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Текущее поведение стенда: поле „Комментарий“ принимает 501 и более символов при наборе с клавиатуры — maxlength=500 не ограничивает ввод (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Подготовить строку из 501 символа «y»
2. Кликнуть в поле «Комментарий» и ввести строку с клавиатуры
3. Проверить длину значения: выбрать поле в панели Elements и выполнить в консоли DevTools $0.value.length
**Ожидаемый результат:**
Поле принимает строку: значение не обрезано, длина равна 501; рядом с полем и на странице нет сообщения об ошибке.
**Приоритет:** Medium
**Статус:** Not Executed
**Примечания:** Регрессионная фиксация текущего поведения (пункты чек-листа с префиксом «Текущее поведение стенда»): тест защищает от ложных ожиданий, а не от бага. Для автотеста: ввод строки и проверка len(value) == 501 программно (замером подтверждён также ввод 505 символов). Вставка через буфер не измерялась (допущение чек-листа) — ручной прогон выполняется набором с клавиатуры.

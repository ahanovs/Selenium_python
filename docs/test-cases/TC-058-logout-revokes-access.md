**ID:** TC-058
**Название тест-кейса:** logout отзывает access-токен серверно
**Связанные требования:** Блок 4, пункт чек-листа: «GET /users/logout/ с валидным токеном → 200 „Вы разлогинены.“; тот же access после logout → 403»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован; access в наличии.
**Шаги:**
1. GET /api/v1/users/logout/ с Authorization: Bearer <access> — проверить код и тело
2. GET /api/v1/users/me/ с тем же access — проверить код и тело
3. POST /api/v1/jwt/create/ с актуальными кредами — получить свежий access для уборки
**Ожидаемый результат:**
1) 200, тело содержит «Вы разлогинены.». 2) 403 «Токен недействителен» — logout НЕ косметический: токен отозван серверно. 3) 200 — свежий access работает (подтверждение для уборки).
**Приоритет:** Low
**Статус:** Not Executed
**Примечания:** Замеры 2026-10-22. После logout для уборки нужен свежий логин (старый access не работает).

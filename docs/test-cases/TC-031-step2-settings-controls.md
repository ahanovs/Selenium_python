**ID:** TC-031
**Название тест-кейса:** Шаг 2: переключатель, тема и язык меняют значения
**Связанные требования:** Блок 3, пункты чек-листа дословно: «Переключатель „Получать уведомления“ (изначально выключен) переключается кликом (P2)» + «Тема оформления: три варианта (Светлая / Темная / Автоматическая), по умолчанию предвыбрана „Темная“, выбор меняет значение (P2)» + «Язык интерфейса: три варианта (Русский / English / Deutsch), по умолчанию „Русский“, выбор меняет значение (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Пройти на шаг 2 «Настройки»: заполнить шаг 1 значениями из TC-028 и кликнуть «Далее»
2. Осмотреть переключатель «Получать уведомления», тему и язык
3. Кликнуть переключатель — включить
4. Кликнуть переключатель ещё раз — выключить
5. Открыть тему и выбрать «Светлая»
6. Открыть язык и выбрать «English»
**Ожидаемый результат:**
Переключатель изначально выключен и переключается кликом в обе стороны (включён → выключен). В теме три варианта (Светлая / Темная / Автоматическая), по умолчанию «Темная»; в поле выбора отображается выбранное значение — «Светлая». В языке три варианта (Русский / English / Deutsch), по умолчанию «Русский»; в поле выбора отображается «English».
**Приоритет:** Medium
**Статус:** Not Executed
**Примечания:** Три проверки шага 2 объединены: один экран настроек. Точка изменения значения — текст кнопки комбобокса (в ручном прогоне — выбранное значение в поле выбора). Покрытие всех вариантов в сводке — TC-036.

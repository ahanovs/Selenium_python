**Название тест-кейса:** Регистрация через UI-форму → автологин в приложение
**Связанные требования:** Блок 5, пункт чек-листа: «Регистрация через форму (Email + Пароль, валидные данные) → автологин и переход в приложение» (P1)
**Предусловия:** Фронт `http://31.59.114.45:3000` доступен; уникальный email генерируется на прогон.
**Шаги:**
1. Открыть `/sign_up`, заполнить Email и Пароль (рецепт Блока 4: не короче 8, не числовой, не похож на username/email)
2. Убедиться, что кнопка «Зарегистрироваться» активна, и кликнуть её
3. Дождаться перехода в приложение
4. Перезагрузить страницу (проверка живости сессии)
**Ожидаемый результат:**
После шага 3 — URL начинается с `/home`, видны «Панель управления», сайдбар (Сервисы, Платежи, Переводы, VPN, Мой профиль), кнопка «Выйти из аккаунта» (инвариант — попадание в приложение; точный лендинг — замер 2026-10-23: `/home/services`). После шага 4 пользователь остаётся в приложении — редиректа на `/login` нет (сессия переживает reload).

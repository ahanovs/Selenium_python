**ID:** TC-022
**Название тест-кейса:** Повторный запуск после 100% начинает новую загрузку
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Повторный клик „Запустить“ после 100%: значение становится меньше 100 (идёт новая загрузка), затем снова 100 и „Готово“ (P3)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Запустить»
2. Дождаться завершения: 100%, статус «Готово»
3. Кликнуть кнопку «Запустить» снова
4. Опрашивать значение, пока оно не станет меньше 100 (но не дольше 5 секунд)
5. Дождаться 100% и статуса «Готово» (не дольше 10 секунд)
**Ожидаемый результат:**
После повторного клика значение становится меньше 100 (идёт новая загрузка); затем снова достигает 100% со статусом «Готово».
**Приоритет:** Low
**Статус:** Not Executed
**Примечания:** Первое чтение после повторного клика может ещё показывать 100, пока не стартовал новый цикл, — поэтому значение опрашивается до появления «меньше 100».

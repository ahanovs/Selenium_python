**ID:** TC-030
**Название тест-кейса:** Валидации полей на шаге 1 нет
**Связанные требования:** Блок 3, пункты чек-листа дословно: «Текущее поведение стенда: валидации полей нет — пустые и мусорные значения („@@@“, „не-мыло“) проходят „Далее“ без ошибок (P2)». До создания TC-030 проверить вручную длинной строкой с реальной клавиатуры, есть ли лимит длины (по коду его нет — тот же класс риска, что maxlength в Блоке 1)
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Оставить поля пустыми и кликнуть «Далее»
2. Вернуться «Назад», ввести мусорные значения: имя «@@@», email «не-мыло», телефон «абв»
3. Кликнуть «Далее»
**Ожидаемый результат:**
Оба раза переход на шаг 2 появляется не позже чем через 5 секунд после клика и проходит без сообщений об ошибках.
**Приоритет:** Medium
**Статус:** Not Executed
**Примечания:** Регрессионная фиксация текущего поведения. Лимит длины: ручной замер 2026-10-10 — 530 символов принято всеми полями, ограничений нет (по коду maxlength на полях тоже нет). В автотесте — ввод строк фиксированной длины (300 символов) с проверкой отсутствия обрезки.

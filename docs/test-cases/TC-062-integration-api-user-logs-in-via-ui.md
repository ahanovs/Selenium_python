**ID:** TC-062
**Название тест-кейса:** Интеграция API→UI: пользователь из API логинится через форму
**Связанные требования:** Блок 5, пункты чек-листа: «Логин через форму пользователем, созданным через API (POST /users/), → вход в приложение (замер 2026-10-23)» + «НАХОДКА: после входа через UI-форму кнопка „Выйти“ отсутствует» (P1/P2)
**Предусловия:** Фронт доступен; пользователь создан через `POST /api/v1/users/` (фикстура make_user), креды известны.
**Шаги:**
1. Открыть `/login`, заполнить Email и Пароль кредами API-пользователя
2. Кликнуть «Войти» и дождаться перехода
**Ожидаемый результат:**
Шаг 2 — URL начинается с `/home`, виден баннер «Панель управления» (задвоен — замер 2026-10-23): API и UI работают с одной базой.
**Дополнительно (НАХОДКА BUG-007):**
Кнопка «Выйти из аккаунта» после UI-логина ОТСУТСТВУЕТ (30+ секунд наблюдения; после UI-регистрации кнопка есть) — тест закрепляет измеренное поведение.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Интеграционный (API↔UI). Замер 2026-10-23. Уборка: API-логин + `DELETE /users/me/` (идемпотентно); logout-сценарий — TC-064 (через UI-регистрацию, см. BUG-007).

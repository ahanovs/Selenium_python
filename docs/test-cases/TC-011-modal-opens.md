**ID:** TC-011
**Название тест-кейса:** Модальное окно открывается; клик внутри не закрывает
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Модальное окно открывается по кнопке „Открыть модальное окно“ поверх страницы, с затемнением фона (P1)» + «Клик внутри модального окна (по контенту) не закрывает его (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×1600); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Открыть модальное окно»
2. Кликнуть по заголовку окна внутри карточки
**Ожидаемый результат:**
Поверх страницы отображается окно с заголовком «Модальное окно», фон за окном затемнён. После клика по заголовку окно остаётся открытым, затемнение сохраняется.
**Приоритет:** High
**Статус:** Автоматизирован
**Примечания:** Решение по ревью (2026-10-06): окно и затемнение — одно состояние оверлея, риск принят. Заголовок подтверждён замером 2026-10-06 (полный текст карточки — «Модальное окно / Пример для автотестирования»).

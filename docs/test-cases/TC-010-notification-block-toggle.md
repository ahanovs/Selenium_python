**ID:** TC-010
**Название тест-кейса:** Текущее поведение стенда: повторное нажатие снимает блок
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Текущее поведение стенда: повторное нажатие „Показать уведомление“ снимает блок, второй блок не добавляется (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Показать уведомление» в разделе «Уведомление» (появляется блок «Информационное сообщение»)
2. Кликнуть кнопку «Показать уведомление» ещё раз
**Ожидаемый результат:**
На странице нет блока «Информационное сообщение».
**Приоритет:** Medium
**Статус:** Автоматизирован
**Примечания:** Регрессионная фиксация текущего поведения (пункты чек-листа с префиксом «Текущее поведение стенда»): тест защищает от ложных ожиданий, а не от бага.

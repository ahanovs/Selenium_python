**ID:** TC-039
**Название тест-кейса:** Дубликаты при регистрации: email отклоняется, username разрешён
**Связанные требования:** Блок 4, пункты чек-листа: «Дубликат email → 400 „user with this email already exists.“» + «Дубликат username → регистрация проходит, username не уникален»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь A зарегистрирован: email E, username U, пароль P (валидный).
**Шаги:**
1. Отправить POST /api/v1/users/ с email = E, ДРУГИМ username, паролем P
2. Проверить код ответа и тело
3. Отправить POST /api/v1/users/ с username = U, ДРУГИМ email, валидным паролем
4. Проверить код ответа и тело
**Ожидаемый результат:**
1–2) 400; ошибка по полю email: «user with this email already exists.». 3–4) 201 — username не уникален, второй аккаунт создан, в ответе пара access/refresh.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Замеры 2026-10-22. Пользователь A из предусловия убирается фикстурой; пользователя из шага 3 удалить отдельно (DELETE /me с его паролем).

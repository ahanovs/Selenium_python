**ID:** TC-051
**Название тест-кейса:** jwt/create: валидные креды дают пару токенов, неверные отклоняются
**Связанные требования:** Блок 4, пункты чек-листа: «jwt/create с корректными кредами → 200, access и refresh» + «неверный пароль, несуществующий email → 401 без раскрытия причины; пустое тело → 400»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован, креды известны.
**Шаги:**
1. POST /api/v1/jwt/create/ с валидными кредами — проверить код и тело
2. POST /api/v1/jwt/create/ с верным email и НЕверным паролем — проверить код и тело
3. POST /api/v1/jwt/create/ с несуществующим email — проверить код и тело
4. Для каждой строки 400-класса отправить POST /api/v1/jwt/create/ (пустое тело; email есть, ключа password нет; пустые строки в обоих полях) — проверить коды и тела
**Ожидаемый результат:**
1) 200; в теле access и refresh (спека обещает 201 — расхождение). 2) 401 «No active account found with the given credentials». 3) 401 с тем же сообщением — существование email не раскрывается. 4) 400 в каждой строке, сообщения required/blank (замер 2026-10-22).
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Замеры 2026-10-22: все ветки подтверждены.

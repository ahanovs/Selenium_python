**ID:** TC-008
**Название тест-кейса:** Тост каждого типа появляется по своей кнопке
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Тост „Операция выполнена успешно!“ появляется по кнопке „Успех“ (P2)»; «Тост „Произошла ошибка!“ появляется по кнопке „Ошибка“ (P2)»; «Тост „Обратите внимание!“ появляется по кнопке „Предупреждение“ (P2)»; «Тост „Информация для вас“ появляется по кнопке „Инфо“ (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×1600); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Успех» в разделе «Toast уведомления»
2. Кликнуть кнопку «Ошибка» в разделе «Toast уведомления»
3. Кликнуть кнопку «Предупреждение» в разделе «Toast уведомления»
4. Кликнуть кнопку «Инфо» в разделе «Toast уведомления»
**Ожидаемый результат:**
После каждого клика появляется тост с текстом: «Успех» → «Операция выполнена успешно!»; «Ошибка» → «Произошла ошибка!»; «Предупреждение» → «Обратите внимание!»; «Инфо» → «Информация для вас». При кликах подряд, без пауз (тост живёт ~3–4 с), тосты отображаются одновременно — новый не заменяет предыдущий (замер 2026-10-07).
**Приоритет:** Medium
**Статус:** Автоматизирован
**Примечания:** На странице две кнопки «Успех» (разделы «Кнопки» и «Toast уведомления») — в шаге назван раздел. Для автотеста: параметризованный тест «кнопка → текст», различение по тексту тоста.

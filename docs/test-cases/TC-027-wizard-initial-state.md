**ID:** TC-027
**Название тест-кейса:** Изначальное состояние wizard
**Связанные требования:** Блок 3, пункты чек-листа дословно: «Изначально: шаг 1 из 3 „Личная информация“, прогресс 0%, кнопка „Назад“ неактивна, „Далее“ активна, все три поля пусты (P1)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Осмотреть wizard: индикаторы шагов, прогресс заполнения, заголовок шага, поля и кнопки
**Ожидаемый результат:**
Индикация «шаг 1 из 3» — первый из трёх индикаторов активен; заголовок шага «Личная информация»; прогресс 0%; все три поля пусты; кнопка «Назад» неактивна, кнопка «Далее» активна.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Поля пусты и активность «Далее» — расширение начального состояния, согласованное с чеклистом.

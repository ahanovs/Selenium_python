**ID:** TC-025
**Название тест-кейса:** Запуск прогресса с клавиатуры
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Запуск с клавиатуры: Tab до фокуса на кнопке „Запустить“ (но не более 50 нажатий), затем Enter запускает прогресс (P3)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено
**Шаги:**
1. Нажимать Tab, пока фокус не окажется на кнопке «Запустить» (но не более 50 нажатий)
2. Нажать Enter
3. Наблюдать страницу в течение 2 секунд
**Ожидаемый результат:**
Фокус оказывается на кнопке «Запустить» не более чем за 50 нажатий Tab; после Enter в течение 2 секунд статус начинается с «Загрузка» или значение больше 0%.
**Приоритет:** Low
**Статус:** Not Executed
**Примечания:** Предел 50 нажатий — чтобы тест не зависел от числа фокусируемых элементов шапки. Точка наблюдения фокуса: в автотесте — document.activeElement; вручную — если на стенде видна рамка фокуса (проверить при ручном прогоне: если рамки нет, ручной вариант выполняется без этого признака).

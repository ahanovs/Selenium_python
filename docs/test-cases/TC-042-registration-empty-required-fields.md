**Название тест-кейса:** Пустые обязательные поля регистрации отклоняются
**Связанные требования:** Блок 4, пункт чек-листа: «Пустые обязательные поля email и password: ключ отсутствует / пустая строка / строка из одних пробелов → 400»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Тестовые данные: уникальный username, валидный пароль и email для дополнения.
**Шаги:**
1. Для каждой комбинации из таблицы отправить POST /api/v1/users/ (email и password по строке)
2. Проверить код ответа и ошибку по соответствующему полю
**Ожидаемый результат:**
400 в каждой строке; сообщение зависит от класса (замер 2026-10-22): отсутствующий ключ — «This field is required.»; пустая строка и строка из пробелов — «This field may not be blank.»; ошибка всегда по соответствующему полю.
**Приоритет:** High
**Статус:** Not Executed

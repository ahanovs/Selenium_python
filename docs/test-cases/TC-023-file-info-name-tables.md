**ID:** TC-023
**Название тест-кейса:** Загрузка файла показывает имя в file-info
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Загрузка файла показывает имя в file-info — таблицей решений: txt → имя совпадает; pdf → имя совпадает (P1)»; «Крайние значения имени в file-info — таблицей решений: кириллица и пробелы → совпадает; без расширения → совпадает; 200 символов → совпадает; эмодзи → совпадает; пустой файл → имя показывается (P2)»; «Тост „Файл „<имя>“ выбран“ появляется после выбора файла и не обрезает длинное имя (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено; во временном каталоге с коротким путём подготовлены тестовые файлы: «test.txt»; «report.pdf»; «отчёт за 3 квартал.txt»; «noext» (без расширения); имя ровно из 200 символов — 196 букв «a» плюс «.txt»; «📄 тест файл.txt»; пустой «empty.txt» (0 байт)
**Шаги:**
1. Выбрать файл «test.txt»
2. Проверить file-info и тост
3. Повторить для остальных файлов таблицы; после каждого файла убедиться, что в file-info только его имя
**Ожидаемый результат:**
Основная таблица (P1): txt → имя совпадает; pdf → имя совпадает. Крайние значения (P2): кириллица и пробелы → совпадает; без расширения → совпадает; 200 символов → совпадает; эмодзи → совпадает; пустой файл → имя показывается. После каждого выбора появляется тост «Файл „<имя>“ выбран»; для длинного имени (200 символов) и эмодзи тост показывает имя целиком, без обрезки. После каждого следующего файла в file-info ровно его имя — предыдущее заменяется.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Строки таблицы подтверждены чтением клиентского кода; ручной замер столбца — до автоматизации; строки exe и «два файла сразу» замеряются до расширения таблицы (открытый вопрос чек-листа). Приоритет строк: P1 — txt и pdf, P2 — крайние значения; при параметризации приоритет наследуется строкой. В автотесте выбор файла — sendKeys в скрытый инпут (обходит кнопку «Выбрать файл»; её диалог проверяется вручную — отдельный ручной пункт). file-info появляется в DOM после первой загрузки. Повторная загрузка: file-info показывает ровно имя нового файла — предыдущее заменяется.

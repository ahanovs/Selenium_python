**ID:** TC-026
**Название тест-кейса:** Перезагрузка страницы во время загрузки
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Перезагрузка страницы во время загрузки: прогресс сброшен, статус „Ожидание“, кнопка снова активна, на странице нет сообщения об ошибке (P3)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Запустить»
2. Дождаться статуса, начинающегося с «Загрузка» (но не дольше 5 секунд)
3. Нажать F5 (обновить страницу)
4. Осмотреть прогресс-бар, статус, кнопку и страницу
**Ожидаемый результат:**
Прогресс сброшен (0%), статус «Ожидание», кнопка «Запустить» активна; на странице нет ошибочного UI — ни баннера или оверлея сбоя, ни текста «ошибка».
**Приоритет:** Low
**Статус:** Not Executed
**Примечания:** Перезагрузка выполняется после появления статуса, начинающегося с «Загрузка», — иначе кейс вырождается в тривиальную проверку обычной перезагрузки.

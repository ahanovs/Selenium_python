**ID:** TC-046
**Название тест-кейса:** GET /users/me/ возвращает данные зарегистрированного пользователя
**Связанные требования:** Блок 4, пункт чек-листа: «GET /me с валидным access-токеном → 200, объект {username, id, email}, значения совпадают с зарегистрированными»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован (полный набор); access из ответа сохранён.
**Шаги:**
1. GET /api/v1/users/me/ с Authorization: Bearer <access>
2. Проверить код ответа и тело
**Ожидаемый результат:**
200; тело — ровно один объект (не массив) с ключами username, id, email; значения совпадают с отправленными при регистрации.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Замер 2026-10-22. Уборка стандартная.

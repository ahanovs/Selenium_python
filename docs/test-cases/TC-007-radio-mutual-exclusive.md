**ID:** TC-007
**Название тест-кейса:** Радиокнопки подписки: изначально не выбраны, взаимоисключающие
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Изначально не выбрана ни одна радиокнопка подписки (P1)» + «Радиокнопки „Подписаться“/„Не подписываться“ взаимоисключающие — выбран ровно один вариант (P1)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Осмотреть радиокнопки «Подписаться на рассылку» и «Не подписываться»
2. Выбрать «Подписаться на рассылку»
3. Выбрать «Не подписываться»
**Ожидаемый результат:**
Изначально обе радиокнопки не выбраны; после шага 2 выбрана только «Подписаться»; после шага 3 — только «Не подписываться»; в каждый момент выбрана ровно одна.
**Приоритет:** High
**Статус:** Not Executed

**ID:** TC-009
**Название тест-кейса:** «Показать уведомление» показывает блок на странице
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Кнопка „Показать уведомление“ показывает на странице блок „Информационное сообщение“ (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Показать уведомление» в разделе «Уведомление»
**Ожидаемый результат:**
На странице появляется блок с заголовком «Информационное сообщение».
**Приоритет:** Medium
**Статус:** Автоматизирован
**Примечания:** Результат автоматизации (test_tc009, прогон ×10 без падений): текст подтверждён — заголовок «Информационное сообщение», текст «Это важное уведомление для пользователя.»; блок сам не исчезает и в чек-лист внесён. Локатор блока — `role=alert` (уникален на странице).

**ID:** TC-047
**Название тест-кейса:** PATCH /users/me/ меняет username; невалидные значения отклоняются
**Связанные требования:** Блок 4, пункты чек-листа: «PATCH /me username → 200; новое значение подтверждается повторным GET» + «PATCH username негатив: пустая строка, 256+ символов, Ё/эмоджи → ожидаемо 400»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован; access в наличии.
**Шаги:**
1. PATCH /api/v1/users/me/ с телом {"username": новое валидное значение}
2. Проверить код, затем GET /me — убедиться, что значение применилось
3. Для каждой строки таблицы негативов отправить PATCH с username=значение (пустая строка; 256 символов; «Ёё-🙂»)
4. Проверить коды ответов
**Ожидаемый результат:**
Позитив: 200 и значение подтверждается GET. Негативы (замеры 2026-10-22): пустая строка → 200 ПРИНИМАЕТСЯ — username можно обнулить (замечание к стенду); 256 символов → 400 «Ensure this field has no more than 255 characters.»; «Ёё-🙂» → 200 принимаются.
**Приоритет:** High

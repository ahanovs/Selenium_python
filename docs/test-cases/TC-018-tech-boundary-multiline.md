**ID:** TC-018
**Название тест-кейса:** Технологическая граница: многословный текст 100 002 символа не ломает страницу
**Связанные требования:** Блок 1, пункт чек-листа дословно: «Технологическая граница: многословный текст около 100 000 символов в поле „Комментарий“ не ломает страницу (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Подготовить многословный текст ровно 100 002 символа (реальные слова с пробелами — односимвольная строка скрывает баги)
2. Установить текст в поле «Комментарий» программно (обход maxlength)
3. Проверить длину значения в DevTools ($0.value.length)
4. Кликнуть по чекбоксу «Согласен с условиями использования»
**Ожидаемый результат:**
Значение установлено целиком: длина равна 100 002. После клика чекбокс отмечен — страница отвечает на действия.
**Приоритет:** Medium
**Статус:** Автоматизирован
**Примечания:** Кейс автотестовый: установка текста без JS вручную не выполняется (вставка из буфера не измерялась — см. ручной ориентир в чек-листе). Проверяемое утверждение — живость страницы после техграницыы; приёмка текста и отсутствие ошибок проверяются попутно. Замер 2026-10-07: программная установка обходит maxlength.

**ID:** TC-033
**Название тест-кейса:** Согласие с условиями управляет кнопкой «Отправить»
**Связанные требования:** Блок 3, пункты чек-листа дословно: «Кнопка „Отправить“ неактивна, пока не отмечено согласие с условиями; снятие отметки снова её блокирует; отметка сохраняется при переходах „Назад“/„Далее“ между шагами (замер 2026-10-10) (P1)» + «Чекбокс „Подписаться на новости“ переключается кликом и сохраняет состояние при переходах между шагами (замер 2026-10-10) (P3) → шаг TC-033»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Заполнить шаг 1 значениями из TC-032 и кликнуть «Далее»
2. На шаге 2 кликнуть «Далее»
3. На шаге 3 осмотреть кнопку «Отправить»
4. Отметить согласие с условиями, осмотреть кнопку
5. Снять согласие, осмотреть кнопку
6. Снова отметить согласие
7. Отметить «Подписаться на новости»
8. Кликнуть «Назад» (шаг 3 → шаг 2), затем «Далее» (шаг 2 → шаг 3)
9. Осмотреть согласие, подписку и кнопку «Отправить»
**Ожидаемый результат:**
Изначально «Отправить» неактивна. После отметки согласия активна; после снятия отметки снова неактивна; после повторной отметки активна. После возврата «Назад» и возврата «Далее» отметки согласия и подписки сохранены, кнопка остаётся активной.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Проверки согласия (P1) и подписки (P3) объединены экраном подтверждения; при параметризации автотеста приоритеты задаются на строку/проверку — падение подписки не перекрашивает согласие.

**ID:** TC-029
**Название тест-кейса:** «Назад» возвращает с сохранением данных; на шаге 1 кнопка снова неактивна
**Связанные требования:** Блок 3, пункты чек-листа дословно: «„Назад“ возвращает на предыдущий шаг с сохранением введённых данных (замер 2026-10-10: значения всех полей возвращаются); после возврата на шаг 1 кнопка „Назад“ снова неактивна (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Заполнить поля шага 1 значениями из TC-028 и кликнуть «Далее»
2. Кликнуть «Назад»
3. Проверить поля шага 1
**Ожидаемый результат:**
После «Назад» — шаг 1, все три поля содержат ранее введённые значения; кнопка «Назад» снова неактивна.
**Приоритет:** Medium
**Статус:** Not Executed

**ID:** TC-041
**Название тест-кейса:** Парольная политика: некорректные пароли отклоняются с внятными сообщениями, техграница принимается
**Связанные требования:** Блок 4, пункт чек-листа: «Парольная политика: короче 8 / целиком числовой / похожий на username → 400 с внятным сообщением по каждой причине; техграница — пароль 5001 символ → 201»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Тестовые данные: уникальные email; username фиксированный для строки «похожий» (например «similarcheck»).
**Шаги:**
1. Для каждой строки таблицы отправить POST /api/v1/users/ (username, уникальный email, password=значение)
2. Проверить код ответа и сообщение об ошибке пароля
**Ожидаемый результат:**
Таблица: «a» → 400 «This password is too short. It must contain at least 8 characters.»; «12345678» → 400 «This password is entirely numeric.»; «Similarcheck1» при username «similarcheck» → 400 «The password is too similar to the username.»; техграница «X7a»×1667 (5001 символ) → 201.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Замеры 2026-10-22. CommonPassword-валидатора нет («qwerty123» принят) — словарную ветку в кейс не включать. Строки с 400 пользователя не создают; успешную техграницу убрать (DELETE /me).

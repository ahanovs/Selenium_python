**ID:** TC-012
**Название тест-кейса:** Модальное окно закрывается кликом по фону и открывается повторно
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Модальное окно закрывается кликом по затемнённому фону (P1)» + «Модальное окно открывается повторно после закрытия (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Открыть модальное окно»
2. Кликнуть по затемнённому фону у левого края экрана, вне окна
3. Кликнуть кнопку «Открыть модальное окно» снова
**Ожидаемый результат:**
После шага 2 окно не отображается, затемнение исчезло. После шага 3 окно отображается, фон затемнён.
**Приоритет:** High
**Статус:** Автоматизирован
**Примечания:** Клик по фону выполняется вне карточки окна. Технические детали (координаты, невидимый дубль в DOM) — в заметках автоматизатора README-индекса.

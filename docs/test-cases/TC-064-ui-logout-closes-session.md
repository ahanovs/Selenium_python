**ID:** TC-064
**Название тест-кейса:** Выход из аккаунта закрывает сессию
**Связанные требования:** Блок 5, пункты чек-листа: «„Выйти из аккаунта“ → редирект на /login, тост „Вы вышли из приложения“, форма „Вход в систему“ доступна» + «НАХОДКА: после выхода прямой заход на /home НЕ редиректит — приложение отображается целиком» (P1/P2)
**Предусловия:** Фронт доступен; пользователь зарегистрирован (API-фикстура) и залогинен через UI-форму `/login`.
**Шаги:**
1. Находясь в приложении, кликнуть «Выйти из аккаунта»
2. Проверить URL и содержимое страницы
3. Прямым переходом открыть `/home`
**Ожидаемый результат:**
Шаг 1 — редирект на `/login`. Шаг 2 — видна форма «Вход в систему», тост «Вы вышли из приложения». Шаг 3 (НАХОДКА, замер 2026-10-23) — редиректа НЕТ: `/home` отображает приложение целиком («Добро пожаловать в Bro AI», сайдбар, «Выйти из аккаунта») — auth-guard на прямые URL не срабатывает, кандидат в BUG-006.
**Приоритет:** High
**Статус:** Blocked
**Примечания:** Замер 2026-10-23 в профиле браузера после UI-logout; на чистом профиле сверить. АВТОМАТИЗАЦИЯ ЗАБЛОКИРОВАНА BUG-007 (расширен 2026-10-23): кнопка «Выйти» рендерится нестабильно — в headless-прогонах панель не рендерится вовсе, в headed панель задвоена без кнопки; в ручной сессии кнопка была. Автотест убран из набора (нестабильный рендер нельзя ассертить); кейс — ручной ориентир до починки фронта. Уборка: API-логин + `DELETE /users/me/`.

**ID:** TC-037
**Название тест-кейса:** Регистрация принимает полный и минимальный наборы полей
**Связанные требования:** Блок 4, пункты чек-листа: «Регистрация полным набором (username + email + password) → 201; в ответе id, username, email и пара access/refresh; пароль в ответе не возвращается» + «Регистрация минимальным набором → 201»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Тестовые данные: уникальные email и username (генерируются на каждый прогон), пароль валиден по политике (не короче 8, не числовой, не похож на username).
**Шаги:**
1. Отправить POST /api/v1/users/ с полным набором: username, email, password
2. Проверить код ответа и тело
3. Отправить POST /api/v1/users/ с минимальным набором: только email и password (без username)
4. Проверить код ответа и тело
**Ожидаемый результат:**
1) 201; в теле username, email, id и пара access/refresh; пароль в теле отсутствует. 2) 201; username пуст или отсутствует, остальное — как в первом сценарии.
**Приоритет:** High
**Статус:** Not Executed

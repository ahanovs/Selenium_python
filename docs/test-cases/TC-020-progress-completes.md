**ID:** TC-020
**Название тест-кейса:** Запуск доводит прогресс до 100% со статусом «Готово» и тостом
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Клик „Запустить“ доводит прогресс до 100%: итог равен 100 и через секунду после завершения остаётся 100; aria-valuenow совпадает с видимым процентом; статус становится „Готово“ (P1)» + «Тост „Загрузка завершена!“ появляется при достижении 100% (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Запустить»
2. Дождаться статуса «Готово» (но не дольше 10 секунд)
3. Сразу проверить появление тоста (тост живёт несколько секунд)
4. Прочитать aria-valuenow и видимый процент — оба равны 100
5. Через секунду после завершения проверить, что значение по-прежнему 100
**Ожидаемый результат:**
Прогресс достигает 100%; итог равен 100 и через секунду после завершения остаётся 100; aria-valuenow равен видимому проценту; статус «Готово»; появляется тост «Загрузка завершена!».
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Пять проверок объединены сознательно: один сценарий запуска, факты одного действия — промежуточные шаги не проверяются (шаг прогресса 10% с интервалом 200 мс, перехват промежуточных значений даёт ошибку разреженной выборки). Точка наблюдения aria-valuenow: вручную — DevTools, в автотесте — get_attribute.

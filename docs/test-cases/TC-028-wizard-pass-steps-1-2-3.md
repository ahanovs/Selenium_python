**ID:** TC-028
**Название тест-кейса:** Прохождение шагов 1 → 2 → 3 с заполнением полей
**Связанные требования:** Блок 3, пункты чек-листа дословно: «Заполненные поля шага 1 после „Далее“ ведут на шаг 2 „Настройки“, прогресс 50% (P1)» + «Шаг 2 после „Далее“ ведёт на шаг 3 „Подтверждение“, прогресс 100% (P1)» + «Поля имени, email и телефона принимают ввод и отображают введённое (P1)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/multi-step-form (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600, фиксирован через CDP); страница только что открыта, wizard на шаге 1, состояние сброшено
**Шаги:**
1. Заполнить поля шага 1 с клавиатуры: имя «Иван Тестов», email «ivan@test.ru», телефон «+7 999 123-45-67»
2. Сразу после ввода проверить значения трёх полей
3. Кликнуть «Далее» и дождаться заголовка шага «Настройки»
4. Кликнуть «Далее» и дождаться заголовка шага «Подтверждение»
**Ожидаемый результат:**
Поля принимают введённые значения. После первого «Далее» — шаг 2 «Настройки», прогресс 50%. После второго «Далее» — шаг 3 «Подтверждение», прогресс 100%.
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Объединено сознательно: один сценарий прохождения wizard, три факта одной цепочки действий. Способ ввода — клавиатура (эталон для Блока 3). Шаги 2–3 отсутствуют в DOM до перехода — автотест ждёт появления контента шага после клика.

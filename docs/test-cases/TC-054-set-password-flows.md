**ID:** TC-054
**Название тест-кейса:** set_password: обычная Bearer-авторизация; неверный current отклоняется
**Связанные требования:** Блок 4, пункты чек-листа: «set_password — успех → 200 {access, refresh}; логин старый → 401, с новым → 200» + «неверный current_password → 400 „Invalid password.“, пароль НЕ сменён» + «новый пароль проходит политику»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован; access, старый и новый пароли в наличии.
**Шаги:**
1. POST /api/v1/users/set_password/ с Authorization: Bearer <access> и телом {"new_password": новый, "current_password": старый} — проверить код и тело
2. POST /api/v1/jwt/create/ со СТАРЫМ паролем — проверить код
3. POST /api/v1/jwt/create/ с НОВЫМ паролем — проверить код
4. POST /api/v1/users/set_password/ с верным Bearer, но неверным current_password — проверить код; логин с паролем, установленным в шаге 1, — убедиться, что пароль не сменился
5. POST /api/v1/users/set_password/ с Authorization: Bearer <access> и телом без поля token (поля валидны) — проверить код: пароль СМЕНИТСЯ — авторизация по заголовку, поле token игнорируется
6. POST /api/v1/users/set_password/ с Authorization: Bearer <access> и телом {new_password короче 8, current_password актуальный} — проверить код
**Ожидаемый результат:**
1) 200, в теле новая пара access/refresh. 2) 401. 3) 200. 4) 400 {"current_password":["Invalid password."]}, старый пароль продолжает работать. 5) 200 — авторизация по заголовку Bearer, поле token в теле игнорируется, пароль сменился. 6) 400 «This password is too short. It must contain at least 8 characters.» — политика применяется и на новом пароле (замеры 2026-10-22, уточнены автотестом и матрицей проб).
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Замеры 2026-10-22, уточнено автотестом: неверный current_password с ЖИВЫМ токеном — 400 «Invalid password.» (403 в первом замере был про отозванный токен). После кейса аккаунт принадлежит последнему успешно установленному паролю — уборка с АКТУАЛЬНЫМ паролем (допущение чеклиста).

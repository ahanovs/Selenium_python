**ID:** TC-003
**Название тест-кейса:** Страна выбирается из списка и отображается в кнопке
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Страна выбирается из списка (Россия, США, Германия, Франция) и отображается в кнопке списка (P1)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×720); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть по кнопке выбора страны
2. Осмотреть открывшийся список
3. Выбрать «США»
**Ожидаемый результат:**
В списке четыре варианта: Россия, США, Германия, Франция. После выбора кнопка отображает «США».
**Приоритет:** High
**Статус:** Not Executed
**Примечания:** Список кастомный (кнопка, не нативный select) — для автотеста; см. заметки автоматизатора.

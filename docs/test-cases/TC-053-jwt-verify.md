**Название тест-кейса:** jwt/verify подтверждает валидный токен и отклоняет мусор
**Связанные требования:** Блок 4, пункт чек-листа: «jwt/verify: валидный токен → 200; мусорная строка → 401»
**Предусловия:** Стенд Bro AI API доступен: http://31.59.114.45:8000/api/v1. Пользователь зарегистрирован; access в наличии.
**Шаги:**
1. POST /api/v1/jwt/verify/ с телом {"token": <валидный access>} — проверить код
2. POST /api/v1/jwt/verify/ с телом {"token": "garbage.string.here"} — проверить код и тело
**Ожидаемый результат:**
1) 200 (спека обещает 201 — расхождение). 2) 401 «Token is invalid or expired» (code token_not_valid).

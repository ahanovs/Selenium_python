**ID:** TC-021
**Название тест-кейса:** Кнопка «Запустить» неактивна во время загрузки и активна после
**Связанные требования:** Блок 2, пункты чек-листа дословно: «Во время загрузки (статус начинается с „Загрузка“) кнопка „Запустить“ неактивна — статус и состояние кнопки читать одним снимком (одним вызовом JS), без пауз; после завершения кнопка снова активна; цикл занимает ~2 с (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/interactive-elements (Chrome, стабильная версия на момент прогона; десктоп; для ручного прогона — любое окно, страница прокручивается; для автотеста вьюпорт 1280×1600 (страница высокая), фиксирован через CDP); страница только что открыта, состояние сброшено
**Шаги:**
1. Кликнуть кнопку «Запустить»
2. Опрашивать страницу, пока статус не начнётся с «Загрузка», затем одним JS-снимком прочитать текст статуса и свойство disabled кнопки
3. Дождаться статуса «Готово» и прочитать состояние кнопки
**Ожидаемый результат:**
Как только статус начинается с «Загрузка», кнопка неактивна (свойство disabled=true в том же снимке); после завершения (статус «Готово») кнопка активна.
**Приоритет:** Medium
**Статус:** Only Automated
**Примечания:** Кейс только автотест: вручную успеть прочитать состояние за цикл 200 мс невозможно. Статус и состояние кнопки читать одним JS-снимком — между двумя отдельными чтениями цикл успевает сменить состояние. Длительность цикла ~2 с сознательно не ассертится: тайминг флакоопасен (прецедент — решение по автозакрытию тостов, Блок 1); утвердить решение — за автором.

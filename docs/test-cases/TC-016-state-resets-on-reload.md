**ID:** TC-016
**Название тест-кейса:** Состояние сбрасывается перезагрузкой страницы
**Связанные требования:** Блок 1, пункты чек-листа дословно: «Заполненные поля и отметки сбрасываются при перезагрузке страницы (P2)»
**Предусловия:** Открыта страница https://lms.threadqa.ru/xpath-practice-hub/practice/basic-elements (Chrome, стабильная версия на момент прогона; десктоп; окно 1280×1600); страница только что открыта, состояние сброшено
**Шаги:**
1. Заполнить поля конкретными значениями: «Имя» — «Тест», «Email» — test@example.com, «Пароль» — Password123, «Комментарий» — «Проверка»
2. Отметить чекбокс «Согласен с условиями использования»
3. Выбрать страну «Германия»
4. Выбрать радиокнопку «Не подписываться»
5. Нажать F5 (обновить страницу)
**Ожидаемый результат:**
Поле «Имя» пустое; поле «Email» пустое; поле «Пароль» пустое; поле «Комментарий» пустое; чекбокс снят; в кнопке страны — «Выберите страну»; обе радиокнопки не выбраны.
**Приоритет:** Medium
**Статус:** Автоматизирован
**Примечания:** Базовая гарантия для автотестов: перезагрузка = чистое состояние.

**ID:** BUG-007
**Заголовок:** После входа через форму логина в приложении нет кнопки «Выйти из аккаунта» (панель управления задвоена)
**Severity:** Major
**Priority:** High
**Окружение:** Фронт Bro AI `http://31.59.114.45:3000` (React SPA), замер 2026-10-23 (30+ секунд наблюдения)
**Воспроизводимость:** путь логина — всегда; путь регистрации — нестабично (в ручной сессии кнопка была, в headless-прогонах панель управления не рендерится вовсе, в headed-прогоне панель задвоена без кнопки — замеры Selenium 2026-10-23)
**Предусловия:** Существующий пользователь (создан любым способом); открыта `/login`.
**Шаги воспроизведения:**
1. `POST /api/v1/users/` — создать пользователя (или использовать зарегистрированного ранее)
2. Открыть `/login`, заполнить Email и Пароль, кликнуть «Войти»
3. Дождаться перехода в приложение и наблюдать не менее 30 секунд
**Ожидаемый результат:**
Приложение отображается с кнопкой «Выйти из аккаунта» — как после пути регистрации.
**Фактический результат:**
Вход успешен (URL `/home/services`, каталог сервисов), но: баннер «Панель управления» продублирован (два совпадения в DOM), кнопки «Выйти из аккаунта» нет вовсе — 0 элементов на протяжении 30+ секунд. Выйти из приложения через интерфейс невозможно. Для сравнения: после пути регистрации (POST-автологин) кнопка присутствует и работает.
**Дополнительно:**
Обходной путь для тестов и пользователей: сессию закрывает сам бэкенд (/users/logout/, /users/me/ после него → 403), но UI-кнопки для этого нет на пути логина.
**Доказательство:** зонд-скрипт 2026-10-23 (30 замеров с шагом 2 с: выйти=0 на каждом); закреплено тестом `test_tc062_integration_api_user_logs_in_via_ui` (tests/test_bro_front.py); кейс TC-062.
**Расширение 2026-10-23 (Selenium-прогоны):** под Selenium кнопка не рендерится и на пути регистрации — headless (1280×1600 и 1280×900): панель управления отсутствует полностью; headed (1280×1600): панель задвоена, обе видимы, кнопки нет. В ручной сессии (IAB-браузер) кнопка рендерилась и работала. Рендер нестабилен — вплоть до потери всей панели.
**Примечания:** гипотеза — при логине фронт рендерит layout из ошибочного состояния (двойной баннер без кнопки); при регистрации состояние другое. Проверить на чистом профиле.

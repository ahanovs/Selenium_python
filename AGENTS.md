# Правила работы агентов в этом репозитории

## Роли

- **Человек** — автор дизайна (чеклист, тест-кейсы), финальный ревьюер, принимает все решения.
- **Агент-автор** — болванки: Page Object'ы, фикстуры, каркасы тестов по кейсам.
- **Агент-ревьюер** — ревью дизайна в чистой сессии (без рассуждений автора).
  Брифинг: `.zcode/skills/ai-reviewer/SKILL.md` — 8 обязательных линз
  (покрытие, консистентность строгости, атомарность, воспроизводимость,
  гигиена данных, трассировка, приоритеты, формулировки) с явным вердиктом
  по каждой; уроки проекта; безопасные пробы стенда. Урок 2026-10-22:
  ревьюер проверяет только заявленные линзы — новая пропущенная линза
  добавляется в брифинг насовсем.
- **Агент-код-ревьюер** — флакоопасные паттерны, качество ассертов, дублирование.

## Стек и стиль кода

- Python, pytest, Selenium 4. Драйверы — Selenium Manager, webdriver-manager не используется.
- Никаких `time.sleep` — только явные ожидания (`WebDriverWait` + `expected_conditions`).
- Приоритет локаторов: `data-testid` > `id` > доступное имя/роль > CSS. XPath — последнее средство.
- Page Object обязателен: тесты не знают о разметке страницы.
- Один проверяемый факт на тест; ассерты осмысленные, без `assert True`.
- Трассировка: ID кейса из `docs/test-cases/` ↔ имя теста в `tests/`.

## Ответственность и роль ИИ

- Каждый артефакт человек должен уметь объяснить без подглядывания. Если агент написал
  слишком много и человек не может защитить решение — артефакт переделывается.
- Роль ИИ честно фиксируется в README.
- Коммиты по стадиям конвейера, с осмысленными сообщениями (стиль: conventional prefix + русский текст).
- Пуш в удалённый репозиторий — только по явной команде человека.
